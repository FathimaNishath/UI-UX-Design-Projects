# TravelWise – Travel Landing Page

A responsive travel landing page designed to create a simple, engaging, and user-friendly experience for travelers.

## My Role

UI/UX Designer

## Design Tool

- Figma

## Project Overview

TravelWise is a travel website concept designed to help users explore destinations and discover travel experiences through a clean and intuitive interface.

## Key Features

- Responsive landing page
- Destination exploration
- Travel-focused visual design
- Clear navigation
- Strong call-to-action sections
- Responsive layouts for desktop, tablet, and mobile

## Design Highlights

- Blue and white travel-focused color palette
- Clear typography and visual hierarchy
- Consistent spacing and card components
- Strong call-to-action buttons
- Responsive grid layouts
- User-focused content structure

## Responsive Design

The design was created for three screen sizes:

- Desktop
- Tablet
- Mobile
