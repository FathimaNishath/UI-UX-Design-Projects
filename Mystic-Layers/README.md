# Mystic Layers – Cake Ordering & Baking App

A mobile application designed to combine cake ordering with baking learning experiences in one simple and engaging platform.

## My Role

UI/UX Designer

## Design Tool

- Figma

## Project Overview

Mystic Layers is a mobile app concept that allows users to explore cakes, place cake orders, learn baking techniques, and manage their orders through a user-friendly interface.

The design focuses on creating a visually appealing experience while keeping navigation and interactions simple.

## Key Features

- Cake discovery and browsing
- Cake categories
- Cake customization
- Cake ordering
- Baking tutorials
- Recipe and learning content
- Cart and checkout
- Payment flow
- Order tracking
- User profile
- Notifications

## Design Highlights

- Soft pink visual theme
- Clean and consistent UI
- Clear visual hierarchy
- Card-based content layout
- Simple navigation
- Consistent buttons and components
- Mobile-first responsive thinking
